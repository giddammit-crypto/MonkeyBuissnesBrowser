# soulm8te 1.0.1

Исправления вкладок, нескольких окон, очистки, адресной строки и ИИ; новые встроенные инструменты.

- Click & Clean теперь использует иконку веника в панели, меню и окне очистки.
- Новая команда «Шрифты страницы»: статусы загрузки веб-шрифтов, поиск и обновление, CSS-семейства. Сбор ограничен 150 элементами и 100 начертаниями; без чтения текста страницы и постоянного опроса.
- Новая команда «Копировать ссылку без рекламных меток»: удаляет известные utm_*, gclid, fbclid и другие campaign-параметры, сохраняя функциональные query-параметры и fragment. Это ручное копирование, адрес открытой страницы не меняется.
- Новая команда «Открыть страницу по HTTPS» для HTTP-страниц.
- Исправлены выбор поисковика в подсказках g/ddg/?, дедупликация URL с разным регистром пути, Enter при IME-композиции. Локальные IP и .local-устройства без явной схемы распознаются как HTTP; явно введённый HTTPS сохраняется.
- Дублирование, восстановление и перенос вкладки сохраняют корректное рабочее пространство и отключение звука.
- Несколько окон используют общий владелец сохранённых данных; устранены восстановление удалённых записей и повторная обработка одной нативной загрузки разными окнами. Приватные загрузки остаются локальными.
- Очистка проверяет параметры и доступность хранилища паролей до удаления данных, очищает CacheStorage вместе с Service Workers и показывает измеренную оценку освобождённого кэша.
- Исправлен порядок React hooks в панели приватности.
- ИИ корректно различает обрыв/таймаут тела ответа, ошибочный JSON и отмену. Задержка ключа измеряется до получения полного ответа.

## Шрифт «Мономах»

На HTTP-странице библиотеки шрифт объявлен по HTTPS без разрешения CORS. Это различие origin; проверка браузера сохраняется. Тот же исходный TTF и CSS успешно отрисованы настоящим Chromium на одном origin в обычном и приватном режимах. Используйте https://biblioteka33.ru/?p=172. Серверные варианты исправления и границы проверки описаны в docs/MONOMAKH_FONT_DIAGNOSIS_1.0.1.md.

DEB, AppImage и SHA256SUMS. Для установки/обновления: `sudo apt install ./soulm8te-1.0.1-linux-amd64.deb`.

Проверки релиза: TypeScript, unit, Electron smoke/features/Voodoo, npm audit, упаковка и ограниченный REA-анализ трёх выбранных встроенных plugin-модулей. Подробности: docs/FUNCTIONAL_AUDIT_1.0.1.md и docs/PLUGIN_ENGINE_AUDIT_1.0.1.md.
