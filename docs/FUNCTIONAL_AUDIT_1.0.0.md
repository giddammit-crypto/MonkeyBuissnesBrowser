## Границы проверки

Runner запрещает UNIX sockets. Native single-instance lock подменялся только существующей opt-in test fixture; production файлы не используют её. Поэтому владение профилем несколькими процессами требует проверки на рабочем столе. Headless backend не поддерживает проверяемый fullscreen; он пропущен. Живой вход Google/YouTube, DRM, сторонние VPN, все сайты интернета и физические устройства не проверялись. Проверки Google/YouTube используют локальные fixtures. Установка на компьютер пользователя дистанционно не выполнялась.

## Ubuntu

`npm run dist:linux` создаёт AppImage и DEB для x86_64. Workflow Ubuntu release повторяет проверки в GitHub Actions без подмены native lock, собирает оба пакета и SHA256SUMS, затем публикует версионный релиз. Существующий релиз не перезаписывается.
