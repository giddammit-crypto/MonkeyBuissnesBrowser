# Расширения, синхронизация, обновления и системный VPN

## Расширения (частичная поддержка)

Менеджер в настройках устанавливает **только распакованные каталоги** после
подтверждения. Он использует API Electron extensions в постоянной обычной
Chromium-сессии, запоминает пути и пытается восстановить их при перезапуске.
Расширения **не устанавливаются в приватную сессию**; доступ к file:// выключен.

Electron не гарантирует совместимость с произвольными Chrome Web Store
расширениями, packed CRX, всеми Manifest V3 API или механизмом автоматического
обновления расширений. Каталог расширения должен сохраняться на диске.
Установка недоверенного расширения может раскрыть содержимое посещаемых сайтов.

## Синхронизация (пока не реализована)

Для полноценной синхронизации потребуется согласованный сервер/провайдер,
аутентификация, защищённое сквозное шифрование с независимым ключом,
модель разрешения конфликтов и явный выбор данных. Пароли и cookies нельзя
передавать в облако без отдельно спроектированного защищённого протокола.
Не следует добавлять в приложение фиктивное состояние «синхронизировано».

## Автообновления (пока не реализованы)

Текущий репозиторий не публикует подписанные релизы/метаданные обновлений.
Нужны подтверждённые ключи подписи, CI выпуска и безопасная цепочка доставки.
Нельзя автоматически запускать непроверенный скачанный исполняемый файл
или молча объявлять обновление установленным.

## Системный WireGuard VPN (пока не реализован)

Импорт конфигурации проверяет и сохраняет профиль, но не создаёт туннель.
Системный VPN требует отдельного привилегированного компонента для
Windows/macOS/Linux, подписанного установщика и управления ключами, DNS,
маршрутами, kill switch и возвратом к сетевому состоянию при сбое.
Прокси приватного режима не равен системному VPN.

Эти ограничения намеренно сохранены, пока отсутствуют тестируемые backend
и системные компоненты. Нельзя заявлять защищённость соединения лишь на
основании валидного конфигурационного файла.
