# soulm8te 1.0.0

Репозиторий MonkeyBuissnesBrowser. Исправления совместимости сайтов и жизненного цикла вкладок.

- Веб-шрифты и CSS больше не блокируются встроенными общими правилами каталогов `/ads/`, `/adserver/`, `/pagead/`. Блокировка рекламных изображений и скриптов, явные пользовательские правила и правила рекламных доменов сохраняются.
- Выгрузка вкладки отменяется, если за время получения позиции страницы пользователь активировал или закрыл её, сменил адрес, начал ввод или открыл связанное окно.
- Позиция страницы восстанавливается при обычном пробуждении и в разделённом просмотре. Сохранённая позиция не применяется к другому адресу.
- Версия пакета, настроек и окна обновлений синхронизирована: 1.0.0.
- Добавлена проверка реальной загрузки CSS, WOFF2, перенаправлений и FontFace API с другого origin в обычном и приватном режиме. Проверяются CORS, изоляция IPC и сохранение блокировки рекламы.
- Устранена уязвимость minimatch в инструментах сборки (GHSA-g3hv-75wg-m249); добавлена проверка зависимостей перед публикацией.
- Ubuntu x86_64: `.deb`, AppImage и SHA256SUMS. Процесс публикации запускает проверки перед сборкой и сохраняет существующие релизы.

Установка или обновление Ubuntu: скачайте `.deb`, откройте терминал в папке загрузки и выполните `sudo apt install ./soulm8te-1.0.0-linux-amd64.deb`.

Для AppImage требуется поддержка FUSE; если она отсутствует, используйте `.deb` или распаковку `--appimage-extract`. Пакет `.deb` настраивает Chromium sandbox.
