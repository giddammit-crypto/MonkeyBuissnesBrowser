# soulm8te 1.0.2

Мастерство управления вкладками, премиальная эргономика полосы вкладок и ультрабыстрое обновление браузера без ручной возни с `.deb`-пакетами.

## 🗂️ Эргономика и дизайн полосы вкладок (Tabs UX)

В релизе 1.0.2 полоса вкладок получила масштабное обновление визуальной гармонии и тактильного отклика:

### ⚡ 1. Мгновенная активация по MouseDown
- Переключение активной вкладки теперь инициируется в момент нажатия кнопки мыши (`onMouseDown`), а не после её отпускания (`click`).
- Время отклика сокращено до < 16 мс (один кадр при 60 fps / два кадра при 120 fps) — вкладка переключается без малейшей визуальной задержки.

### 🎯 2. Прецизионный Drag & Drop с лазерной линией вставки
- **Двусторонняя детекция позиции (`dragOver left / right`):** полоса определяет, к какому краю соседней вкладки ближе курсор (левая или правая половина), исключая случайную перестановку «не туда».
- **Неоновая линия вставки:** вертикальный светящийся маркер 3.5px в фирменном циане (`var(--signal, #00d2ff)`) с мягкой анимацией лазерного луча (`tabDropGlow`) наглядно показывает будущий слот вкладки.
- **Тактильный захват (`.dragging-tab`):** взятая вкладка деликатно уменьшается (`scale(0.96)`) с полупрозрачностью `0.45` и переключением курсора на `grabbing`.
- **Защита закреплённых вкладок:** закреплённые вкладки защищены от случайного выдергивания мышью.

### 💤 3. Спящие вкладки (Smart Hibernation & RAM Saver)
- **Криогенный Cyberpunk-бейдж «Спит»:** аккуратный чип с закруглением `999px`, тонкой полупрозрачной рамкой и анимированной точкой лунного свечения (`sleep-pulse`).
- **Визуальный покой:** неактивная спящая вкладка снижает яркость фавиконки (`grayscale(35%) opacity(0.72)`) и использует курсивный заголовок с сохранением контраста по стандарту WCAG AAA.
- **Мгновенное пробуждение:** при наведении курсора фавиконка и заголовок плавно оживают (100% цветности), а клик по вкладке моментально восстанавливает страницу из выгруженного состояния.
- **Адаптивность:** при сильном сжатии вкладок (< 160px) текстовый бейдж скрывается через container queries, сохраняя читаемость названия.

### 🔊 4. Живая аудио-индикация, Mute в 1 клик и хоткей Ctrl+M
- **Анимированный эквалайзер (`.tab-audio-button.audible`):** звучащая вкладка пульсирует неоновым бирюзовым свечением с мягким ореолом, позволяя мгновенно найти источник звука среди десятков вкладок.
- **Глушение без смены вкладки:** клик по динамику выключает/включает звук (`Mute/Unmute`) без активации вкладки и без прерывания текущей работы.
- **Хоткей Ctrl+M:** быстрое отключение/включение звука активной вкладки с клавиатуры по стандарту Google Chrome.
- **Заглушить остальные вкладки:** новый пункт в контекстном меню вкладки позволяет в 1 клик заглушить фоновые вкладки.
- **Защита от паразитного драга:** кнопка звука и крестик закрытия изолированы от событий перетаскивания, исключая случайный запуск drag-and-drop при клике.
- **Яркий Cyberpunk Mute-статус (`.muted`):** перечёркнутый динамик окрашен в контрастный неоново-рубиновый оттенок (`#ff3366`) с эффектом подсветки при наведении.
- **Закреплённые вкладки:** на закреплённых вкладках аудио-кнопка элегантно размещается миниатюрным оверлеем в правом нижнем углу фавиконки, не загораживая значок сервиса.

### 🖱️ 5. Удобные жесты, горизонтальный скролл и эргономика закрытия
- **Горизонтальный скролл полосы колесом мыши:** вертикальное вращение колесика мыши над переполненной полосой вкладок плавно прокручивает вкладки влево и вправо.
- **Супер-скролл (Shift + Wheel):** ускоренная в 3.5 раза прокрутка для мгновенной навигации по десяткам открытых вкладок.
- **Быстрое переключение вкладок (Alt + Wheel):** вращение колесика с зажатой клавишей Alt циклически переключает вкладки вперед/назад прямо над лентой.
- **Закрытие средней кнопкой мыши (колёсиком):** клик колёсиком в любой точке вкладки мгновенно закрывает её.
- **Бесшовный переход к соседней вкладке:** при закрытии активной вкладки фокус переходит на ближайшую логическую вкладку без скачков скролла.
- **Двойной клик по полосе:** быстрое открытие новой вкладки по двойному щелчку в свободной области панели.
- **Контекстное меню полосы:** правый клик по свободному пространству полосы открывает системное меню управления вкладками.

## 🔮 Полное включение и выключение AI-Ассистента Вуду

По многочисленным просьбам пользователей в релизе 1.0.2 добавлена возможность **полного выключения ассистента Вуду**:
- **Исчезновение всех иконок:** при выключении Вуду значок робота на верхней панели инструментов, плавающий кружок в правом нижнем углу экрана, кнопка суммаризации в адресной строке и пункт контекстного меню «Анализировать с ВуДу» полностью исчезают из интерфейса.
- **Отключение фоновых процессов и горячих клавиш:** сочетание клавиш <kbd>Ctrl+Shift+V</kbd> деактивируется, фоновые запросы не отправляются.
- **Быстрое управление в 1 клик:**
  - **Кнопка выключения (⏻):** прямо в шапке окна чата Вуду добавлена кнопка питания для моментального отключения.
  - **Правый клик по значку на панели инструментов:** ПКМ по иконке Вуду на верхней панели отключает ассистента в 1 клик.
  - **Контекстное меню плавающего кружка:** ПКМ по кружку в углу экрана позволяет скрыть кружок или полностью выключить Вуду.
  - **Включение обратно в любой момент:** даже когда все иконки скрыты, Вуду можно вернуть в 1 клик через **Главное меню браузера (`⋯`) → «Включить AI-Ассистент Вуду»** или в разделе **«Настройки» → «AI-Ассистент Вуду»**.
  - **Статус-бейдж в Настройках:** наглядный индикатор состояния (*● Включен* / *○ Полностью выключен*) с защитой от случайного сброса настроек видимости.

## 🚀 Обновление браузера обновлёнными файлами (без ручной возни с `.deb`)

Вам больше не требуется каждый раз скачивать тяжёлый `.deb`-пакет, вводить пароль суперпользователя `sudo`, рисковать конфликтами пакетов в ОС или вручную перезаписывать системные директории. 

soulm8te поддерживает быстрое обновление файлами приложения:

### Способ 1: Для пользователей из репозитория / рабочей директории
Если вы запускаете soulm8te из репозитория, обновление происходит буквально в две команды:
```bash
# Получить свежие обновления
git pull

# Пересобрать интерфейс и ядро
npm run build
```
После этого браузер готов к запуску:
```bash
npm start
```
*Либо соберите готовую распакованную папку без прав root:*
```bash
npm run package
```
Готовый бинарник будет лежать в `release/linux-unpacked/soulm8te`. Системный лаунчер `~/.local/bin/soulm8te` или ярлык в меню приложений сразу запускает обновлённую версию!

### Способ 2: Замена файлов распакованного приложения (Portable / Unpacked)
Если вы используете портативную или распакованную версию soulm8te:
1. Загрузите архив со свежими файлами сборки (`linux-unpacked` или `dist.tar.gz`).
2. Распакуйте файлы поверх текущей папки приложения (или обновите каталог `dist/` и `resources/app.asar`).
3. Запустите браузер — все ваши профили, история, закладки, пароли и настройки сессий сохраняются в каталоге пользователя (`~/.config/soulm8te`) и остаются в полной безопасности.

### Способ 3: Графическое автообновление в 1 клик
- В браузере перейдите в **Главное меню (`⋯`) → «Обновления»** либо откройте **«Настройки» → «О браузере»**.
- Окно обновления покажет изменения релиза 1.0.2 и скачает нужный файл в фоне с неоновым прогресс-баром.
