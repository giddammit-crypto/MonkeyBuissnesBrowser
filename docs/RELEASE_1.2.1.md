# soulm8te 1.2.1

- Исправили обновление и удаление пакета DEB. Скрипт установки сохраняет файл, поставленный dpkg, и удаляет старую копию браузера. Команда `soulm8te` запускает обёртку с проверкой sandbox.
- Загрузчик проверяет размер и доступную контрольную сумму, сохраняет готовый файл под свободным именем и убирает временные файлы при сбое. Перед открытием скачанный пакет повторно проверяется.
- После перехода на другой адрес в той же вкладке панель OSINT очищает результаты предыдущей страницы.
