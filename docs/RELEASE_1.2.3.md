# soulm8te 1.2.3

- Заметки загружаются при открытии панели. Фоновые обновления браузера больше не пересылают весь архив заметок. Вуду получает только активную вкладку и настройки помощника, причём обновление отправляется при изменении этих данных.
- Для записи сессии используются поля, нужные для восстановления вкладок. Убрано повторное построение полного состояния каждой вкладки.
- В панели заметок можно сохранить отдельную запись в TXT или весь архив в JSON. Экспорт сохраняет свежий черновик перед открытием системного диалога и заменяет файл после успешной записи.
- Запоздалое автосохранение больше не восстанавливает заметку, которую удалили из другого окна. Создание обычной заметки из приватной вкладки не записывает её адрес и заголовок в профиль. Вуду тоже не получает эти поля из приватной вкладки.
- Горячая клавиша снимка вкладки использует единый обработчик для веб-страницы и интерфейса браузера, в том числе при закрытии редактора.
