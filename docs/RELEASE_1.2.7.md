# soulm8te 1.2.7

Поиск в диспетчере задач показывает число совпадений и общее число процессов. Показатели памяти и средней нагрузки CPU относятся ко всему браузеру. Заголовки столбцов доступны с клавиатуры, активная сортировка озвучивается программами экранного доступа. Компоновка адаптирована к узким окнам и системной настройке уменьшения анимации.

Скрытое окно приостанавливает периодический опрос процессов. При возвращении диспетчер запрашивает свежие показатели.
