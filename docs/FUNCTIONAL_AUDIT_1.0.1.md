# Функциональная проверка 1.0.1

Дата: 5 ноября 2026. База: main df00aa5d7a8d92d36e4f411c7d2b8c1179451c62 (1.0.0). Работа распределена по шести экспертным ролям: тестирование, разработка ПО, Chrome, Chromium, fullstack и дизайн.

## Новые встроенные инструменты

- «Шрифты страницы»: чтение только metadata шрифтов, максимум 150 DOM-элементов и 100 FontFace, строка до 256 символов, таймаут 3 секунды. Работает по явному запросу, без polling, текста, HTML, cookies и URL шрифтов. CSS stack не выдаётся за доказательство выбора каждого глифа. Отказ при закрытии/навигации вкладки, защита неактивной private вкладки.
- «Копировать ссылку без рекламных меток»: ручной компактный аналог части задач ClearURLs; исходная страница не перенаправляется и функциональные параметры сохраняются. Это не полная база правил ClearURLs.
- «Открыть страницу по HTTPS»: явный переход пользователя, без выключения проверки CORS/TLS.

Модальное окно шрифтов проверено при ширине 360 и 680 px: нет горизонтального переполнения, работают поиск, обновление, Escape и удержание фокуса. Native overlay входит в управление слоями оболочки.

## Проверки

Локальный финальный `npm run check`: 72 файла / 649 тестов, TypeScript и release assets — успешно. `npm audit`: 0 уязвимостей.

До публикации выполняются `npm run check`, `npm audit`, `npm run build`, `test:e2e:features`, `test:e2e:voodoo`, `test:e2e:smoke` (включает новый двухоконный сценарий). Features включает новый release-ui-smoke, проверяющий очистку, веник, clipboard, шрифты, IME/search и loading→data.

Локальные проверки Electron используют документированную opt-in подмену single-instance lock: runner запрещает UNIX sockets. Production не импортирует её. Headless полноэкранный режим рабочего стола не проверяется. GitHub Ubuntu release выполняет тот же набор без подмены, проверяет зависимости, собирает DEB/AppImage и SHA256SUMS, проводит ограниченный REA-проход трёх модулей пакета и сохраняет его Evidence как artifact до публикации.

## Что означает оптимизация

Устранено дублирование кешей сохранённых данных между окнами; private/runtime ownership не разделяется. Новый инспектор ограничивает объём чтения и не работает в фоне. Измерение задержки ИИ исправлено, но процентное ускорение внешнего провайдера не заявляется. Установка на компьютер пользователя не выполнялась.

## Границы вывода

Это аудит интеграции Electron/Chromium и перечисленных пользовательских сценариев, не доказательство отсутствия всех ошибок в Chromium и не аудит миллионов строк исходников Blink/V8. GPU/драйверы, DRM, живые логины Google, все расширения Web Store и все сайты не проверены. Settings/session persistence нескольких независимых процессов требует отдельной проверки; общий BrowserStores исправляет окна текущего процесса. Ограничения локальных расширений, прокси, медиа и REA приведены в [PLUGIN_ENGINE_AUDIT_1.0.1.md](PLUGIN_ENGINE_AUDIT_1.0.1.md).

[Диагностика «Мономаха»](MONOMAKH_FONT_DIAGNOSIS_1.0.1.md) разделяет сетевые наблюдения, локальное реальное воспроизведение TTF/CORS и ограничения живого просмотра в этой среде. Сайт на сервере не редактировался.
