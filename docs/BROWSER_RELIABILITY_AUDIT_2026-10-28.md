# Надежность браузера: YouTube, приватность и сохранность данных

Дата: 28 октября 2026 года. База этапа: `c14c8d2`.

## Область

Этот этап проверяет оставшиеся ошибки работающего браузера, прежде всего отсутствие **иконок самого интерфейса YouTube: поиска, меню, лайка, колокольчика и проигрывателя**. Это не запрос о кнопках скачивания MP4/MP3. Проверены фильтрация ресурсов сайта, переключатель AdBlock, thumbnail pipeline, заметки, импорт закладок, favicon и закрытие вкладок. Выводы основаны на коде и отдельно перечисленных тестах; это не утверждение о полном исправлении браузера или всех вариантов живого YouTube.

Предыдущие `APPLICATION_AUDIT_2026-10-28.md` и `PERFORMANCE_AND_FEATURE_AUDIT_2026-10-28.md` описывают исторические этапы. Их тестовые числа не подставляются вместо текущей проверки.

## Подтвержденные находки

| ID | Приоритет | Базовое поведение / причина | Исправление или граница |
|---|---|---|---|
| REL-01 | Высокий | FilterEngine проверял path rules через весь raw URL, включая query. Обычный script/style/font/SVG запрос с рекламным URL/`pixel.gif`/`/ads/` внутри query ошибочно блокировался | Исправлен matching по pathname вместо всего raw URL; nested query URL не считается адресом ресурса. Native baseline fixture воспроизводит блокировку. Это может восстановить ресурсы страницы, но не доказывает единственную причину всех пропавших иконок в реальном профиле пользователя |
| REL-02 | Высокий | YouTube in-page adblock устанавливал CSS/обработчики независимо от пользовательского сетевого AdBlock switch и site exception | DOM blocker теперь получает boolean policy от main и учитывает global/site настройки; при выключении удаляет CSS/timer/observer и возвращает playback rate/mute, если их менял blocker. In-page download controls остаются отдельными от этой policy |
| REL-04 | Высокий | Native image thumbnail декодировал полный скачанный файл синхронно до resize; startup мог запускать много missing thumbnails | Добавлена очередь: один render одновременно, до32 pending, source до8 МиБ/12 млн пикселей, bounded header parse до64КиБ, thumbnail120×120 и result до128КиБ. Windows/macOS используют async native API; Linux — async bounded disk IO и последовательный синхронный decode ограниченного raster до12MP (~48МБ RGBA), с yield между заданиями. Неподдерживаемые/слишком большие файлы сохраняют file icon; stale result после удаления/dispose не записывается. Нет заявления об обнаруженном RCE |
| REL-05 | Высокий | `saveNote` при добавлении501-й заметки записывал `[new,...old].slice(0,500)` | Исправлено: добавление при500 записей дает понятную ошибку до изменения store, старые записи сохраняются; редактирование существующих доступно. Ошибка также видна в drawer через role=alert. Три целевых регрессии проверяют byte-exact disk preservation, reload, update oldest и добавление500-й |
| REL-06 | Высокий | SiteFavicon использовал Google s2 fallback без информации о private mode; shell запрос передавал hostname страницы наружу | Google s2 fallback удален глобально; без favicon используется локальная Globe иконка. Явно объявленный сайтом favicon пока загружается в shell scope: это отдельная оставшаяся граница, не заявлена полная маршрутизация всех иконок через исходный tab session |
| REL-07 | Средний, осталось | `closeTab` удаляет metadata до native close; `detachView` вызывает close без ожидания beforeunload | Unsaved form может исчезнуть без возможности site veto. Hibernation guards не защищают manual/agent close. Нужен полноценный beforeunload-aware lifecycle, а не обещание, что приложение сохраняет формы |
| REL-08 | Средний | Chromium bookmarks importer пропускал поврежденные/нечитаемые Bookmarks/AccountBookmarks и возвращал imported0 без ошибки | Исправлено: все файлы недоступны — явный report.errors без записи; часть доступна — импорт доступного и warning с именами остальных файлов. Шесть целевых регрессий проверяют invalid JSON/roots, частичный импорт и допустимый пустой документ; исходники/существующие записи сохраняются |

Приоритет не означает подтвержденную эксплуатацию злоумышленником. REL-05 и REL-06 — конкретные ошибки сохранности/передачи данных, REL-04 — риск чрезмерной RAM/CPU нагрузки.

## Граница диагностики YouTube

Найдена воспроизводимая общая причина повреждения интерфейса: ложная блокировка необходимых script/style/font/SVG ресурсов по query. Это подтвержденный дефект фильтра, который может затрагивать штатные кнопки сайта. Дополнительно устранено несоответствие DOM AdBlock переключателю пользователя. Без проверки реальной страницы в исходном профиле нельзя утверждать, что все исчезнувшие иконки имеют только эту причину: сайт, cache, авторизация и экспериментальная разметка могут отличаться от fixture. Локальные проверки ресурсов и policy перечисляются в разделе результатов, без подмены их утверждением о проверке живого YouTube.

## Конкретный следующий функционал

Предлагаются два небольших направления после текущих исправлений:

- **Безопасное закрытие вкладки с несохраненным вводом.** Запускать native beforeunload, сохранять tab metadata до фактического закрытия, обрабатывать отказ пользователя и не ломать close/reopen/private/split. Это напрямую закрывает REL-07; тесты должны проверять и принятие, и отмену.
- **Экспорт заметок в Markdown/JSON.** После явной ошибки заполненного store пользователь получает способ сохранить свои записи и освободить место. Нужны native Save dialog, escaping/валидный JSON, atomic write и round trip для нескольких заметок. Это предложение, не заявленная реализованная функция этого этапа.

Большие cloud sync, системный VPN, полная Web Store совместимость и все возможности других браузеров не входят в эти предложения.

## Оставшиеся границы

Внешний yt-dlp/ffmpeg, реальные YouTube аккаунты/регион/DRM, live xkiro и модельные квоты не подтверждаются локальными fixture tests. Контекст Вуду остается default/max250000, без стандартного общего лимита числа шагов; token estimator приблизительный и реальная capacity зависит от провайдера. История и snapshot тяжелых store могут требовать дальнейшего lazy loading; фикс thumbnail не означает измеренного ускорения всего браузера. Cloud sync, системный VPN backend и подписанные автоматические обновления по-прежнему не реализованы; никакая строка отчета не означает полного runtime аудита всех функций/сайтов/ОС.
