# soulm8te 1.0.3

Веб-стандарты и эргономика вкладок в одном выпуске: совместимость веб-шрифтов, встроенный
PDF-просмотрщик, собственный XSLT-движок, веник в Click & Clean, исправления аудита — плюс всё,
что вошло в 1.0.2: мгновенная активация вкладок по MouseDown, лазерная линия вставки при
перетаскивании, спящие вкладки, аудио-индикация и глушение по Ctrl+M, быстрое обновление из
GitHub без ручной работы с пакетами.

## Что нового

- **Click & Clean — настоящий веник.** Кнопка на панели, пункт главного меню и окно очистки
  используют собственную иконку веника (ручка + обойма + веер щетины) вместо тонкой кисти из набора
  иконок. Рисуется в сетке 24×24 тем же штрихом, что и остальные иконки панели.
- **Совместимость веб-шрифтов.** Шрифт, объявленный по HTTPS на HTTP-странице, больше не
  отбрасывается только из-за отсутствия `Access-Control-Allow-Origin`, если сама страница не
  запрещает запрос (CSP/CORP и запрет политикой сохраняются). Это возвращает поведение до Chrome
  143 — на `http://biblioteka33.ru/?p=172` шрифт «Мономах» применяется. Настройка
  «Совместимость шрифтов» отключается; в строгом режиме действует проверка CORS.
- **Панель «Шрифты страницы».** Показывает точную причину, почему шрифт не отображается
  (блокировка/404/сеть, CORS/CORP, отсутствие гарнитуры в системе, ошибка декодирования), и умеет
  подставить похожие локальные семейства. Сбор ограничен 150 элементами и 100 начертаниями.
- **PDF открывается во вкладке.** Встроенный просмотрщик Chromium включён: документ открывается по
  своему адресу без скачивания файла.
- **Собственный движок XSLT 1.0 + XPath.** Chrome 158 (17.11.2026) удаляет XSLT, поэтому браузер
  сам применяет `<?xml-stylesheet?>` для RSS/Atom и sitemap: адрес сохраняется, стиль кешируется на
  5 минут, при ошибке показывается полоса с причиной вместо «тихого» сырого XML. Ограничения:
  документ 4 МБ, стиль 1 МБ, вывод 8 МБ, только same-origin; `document()`, `key()`, `xsl:script` и
  внешние сущности запрещены. Отключается настройкой.

## Исправления аудита 1.0.2

- **Масштаб.** Повреждённый или нулевой сохранённый коэффициент больше не отправляет Ctrl «+»
  сразу на 500 %: значение проверяется и ограничивается крайними ступенями.
- **Адресная строка.** Пустой запрос после «?» даёт подсказку вместо поиска пустой строки; полные
  имена хостов с точкой на конце (`example.com.`) открываются как адрес, а не как поиск.
- **XSLT, несколько окон.** Учёт XML-ответов, уже применённых преобразований и числа ослабленных
  шрифтовых ответов стал общим для окон одной сессии, поэтому преобразование не теряется при
  открытии вкладки в другом окне. Неудачная попытка больше не помечает документ как обработанный —
  следующий `dom-ready` повторяет её.
- **Производительность.** Сообщения консоли сайта проходят дешёвый предварительный фильтр, поэтому
  на «болтливых» страницах регулярные выражения больше не выполняются для тысяч посторонних
  сообщений.

## Проверки

`npm run check` (TypeScript, 673 unit-теста, контроль иконок и версии), `npm run build`,
Electron e2e: features (split view, экспорт закладок, иконки YouTube, шрифты сайта, XSLT, PDF),
smoke и Voodoo, `npm audit`, упаковка DEB/AppImage и ограниченный REA-анализ трёх встроенных
plugin-модулей. Ограничения и границы утверждений — в `docs/ACCEPTANCE.md` и
`docs/CHROMIUM_ENGINE_AND_PLUGINS_AUDIT_2026-11-05.md`.

## Что вошло из 1.0.2

- **Вкладки.** Активация по `MouseDown`, двусторонняя детекция позиции при перетаскивании с неоновой
  линией вставки, тактильный захват, защита закреплённых вкладок, бейдж «Спит» с плавным
  пробуждением, анимированный эквалайзер звучащей вкладки и глушение без переключения (Ctrl+M).
- **Обновление браузера.** Запрос к GitHub API через нативный `fetch` с авторизационным токеном,
  повторами при 5xx и понятным сообщением вместо «голой» ошибки 503; обновление выполняется файлами
  без ручной установки `.deb`.
- **Заметки и поиск по вкладкам.** Быстрые заметки в выдвижной панели и поиск по вкладкам с
  клавиатуры.
- **Вуду.** Улучшенная панель чата и поведение плавающего пузыря.
