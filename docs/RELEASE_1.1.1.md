# soulm8te 1.1.1

- User-Agent соответствует версии встроенного Chromium. Вкладки используют штатные браузерные API и Client Hints. Локальный тест подтверждает обработку клика и обмен cookies в HTTPS-виджете проверки.
- Восстановлена загрузка изолированного скрипта вкладок. Исправлены защита несохранённых форм, очистка состояния при выгрузке вкладки и обработка навигации во фреймах.
- Chromium проверяет цепочку доверия TLS. Автозаполнение передаёт пароль только на точный HTTPS-источник, для которого он сохранён. Генератор паролей использует Web Crypto.
- Распакованные расширения используют общий список в окнах одной сессии. Установку, перезапуск, удаление и изоляцию приватных вкладок проверили на локальном расширении Manifest V3.
- Исправлены открытие адреса или поискового запроса через Alt+Enter, редактирование запроса поиска по вкладкам, быстрые переключения вкладок и обновление индикатора сохранённых паролей.

Проверка Cloudflare на `lasthavens.com` требует ручного подтверждения. Из тестовой сети сайт открыл обычную страницу.
