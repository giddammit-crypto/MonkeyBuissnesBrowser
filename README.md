# SOUL-M8TE Browser

Electron-браузер с настоящими вкладками Chromium и интерфейсом по SOUL-M8TE Brand Guidelines 1.0. Бренд обновлён; техническое имя пакета, appId, каталог профиля и прежняя Chromium partition сохранены для совместимости с существующими данными MonkeyBuissnesBrowser.

## Запуск

Нужен Node.js 24+ и npm. Рекомендуемый путь установки зависимостей — `npm ci`.

```bash
npm ci
npm run check
npm run build
npm start
```

Если среда намеренно отключает lifecycle scripts npm, Electron binary устанавливается явно: `node node_modules/electron/install.js`. В обычной установке этот шаг выполняет npm.

## Возможности

- Вкладки, рабочие пространства, история и закладки; навигация, загрузка и остановка страницы.
- Закрепление, отключение звука, дублирование, восстановление закрытых обычных вкладок.
- Восстановление обычной сессии с ленивой загрузкой фоновых вкладок.
- Поиск по странице, масштаб и системная печать.
- Нативное сохранение файлов, прогресс, пауза, продолжение и отмена текущей загрузки. Продолжение зависит от поддержки сервером.
- Приватные вкладки в общей временной сессии, очистка после последней приватной вкладки, отдельные данные сайтов. Приватные URL и записи загрузок не записываются в JSON-хранилища.
- Опциональный HTTP/HTTPS/SOCKS5-прокси для приватной сессии. Адрес и настройка живут только в памяти; туннель или Tor не входят в комплект.
- Базовая блокировка рекламных запросов и сторонних cookies, переключатели в настройках.
- Автоусыпление фоновых вкладок, исключения для закрепления, звука, загрузок, несохранённого ввода и разрешённого захвата медиа.
- Запросы разрешений для HTTPS-сайтов; разрешение действует на текущую сессию.
- Импорт локальных профилей Chrome, Яндекс Браузера, Firefox, Edge, Brave, Opera и Vivaldi; HTML-закладки и CSV-пароли. Подробнее — [IMPORT.md](docs/IMPORT.md).
- Тёмная, светлая и системная темы, доступные кнопки, адаптация окна от 920×640.

## Клавиатура

| Действие | Windows/Linux | macOS |
| --- | --- | --- |
| Адресная строка | Ctrl+L | Cmd+L |
| Новая вкладка | Ctrl+T | Cmd+T |
| Приватная вкладка | Ctrl+Shift+P или Ctrl+Shift+N | Cmd+Shift+P или Cmd+Shift+N |
| Закрыть / восстановить | Ctrl+W / Ctrl+Shift+T | Cmd+W / Cmd+Shift+T |
| Поиск по странице | Ctrl+F | Cmd+F |
| Закладка | Ctrl+D | Cmd+D |
| История / загрузки | Ctrl+H / Ctrl+J | Cmd+H / Cmd+J |
| Печать | Ctrl+P | Cmd+P |
| Масштаб | Ctrl+Plus / Minus / 0 | Cmd+Plus / Minus / 0 |

*Системные сочетания могут перехватываться ОС. Действия доступны и через меню приложения.

## Проверки и сборка

```bash
npm run typecheck
npm test
npm run build
npm run test:e2e:smoke
npm run package          # каталог приложения без установщика
npm run dist:linux       # AppImage + deb
```

E2E самостоятельно запускает Electron и локальный HTTP-сервер, использует временный профиль, проверяет навигацию, вкладки, приватность, файлы и прокси. На Linux работает headless; только тестовый запуск от root добавляет `--no-sandbox`. В приложении sandbox остаётся включённым.

GitHub Actions проверяет проект на Ubuntu и собирает каталоги приложения на Linux, Windows и macOS. Результат каждой платформы надо проверять на целевой системе; сборка в CI не равна проверке интерфейса на этой ОС. Установщики не подписаны, автообновление пока не реализовано.

## Приватность и ограничения

Приватный режим защищает локальную историю, но самостоятельно не скрывает IP и не делает браузер аналогом Tor Browser. Прокси требует работающего внешнего сервера; полная защита от fingerprinting и DNS-утечек не заявляется. Файлы и закладки, явно сохранённые пользователем, остаются на диске. Подробности — [PRIVACY.md](docs/PRIVACY.md).

WireGuard-профиль можно проверить и сохранить в защищённом хранилище; приложение не поднимает системный VPN-туннель. Полноценные расширения Chrome, синхронизация аккаунта, автозаполнение паролей, безопасное автообновление и DRM/Widevine пока не реализованы. Прямой импорт защищённых Windows DPAPI/App-Bound и Firefox NSS паролей не поддерживается; доступен официальный CSV-экспорт и импорт в локальное защищённое хранилище. Автозаполнение остаётся отдельной задачей.

Архитектура — [ARCHITECTURE.md](docs/ARCHITECTURE.md). Подробный аудит и снимки интерфейса передаются владельцу проекта отдельно.

Google/YouTube могут отклонять встроенный вход в аккаунт. Для соответствующих страниц есть пояснение и подтверждаемое открытие системного браузера; его сессия не синхронизируется обратно. Фильтр cookies учитывает schemeful site и Public Suffix List, поэтому соседние поддомены сайта не блокируются как сторонние. В обычном профиле включён отключаемый режим совместимости cookies узлов входа Google / YouTube; остальные сторонние cookies фильтруются. Дополнительные исключения задаются явно для отдельных сайтов и не ослабляют приватную сессию. Подробнее: [вход в Google / YouTube](docs/SIGN_IN.md).
