## 🌟 Ключевые возможности

### 🎨 1. Адаптивный неоновый дизайн и темы под обои
- **Динамическая адаптация темы:** цвет шапки, кнопок, вкладок, акцентов и границ автоматически подстраивается под доминирующий цвет текущих обоев.
- **Новые акцентные палитры:** поддержка цветов *Белый*, *Молочный*, *Графитовый*, *Синий*, *Бирюзовый*, *Фиолетовый*, *Розовый* с адаптивным расчётом контраста кнопок и шрифтов для идеальной читаемости.
- **6 встроенных премиум-обоев в стилях Cyberpunk и Detroit:**
  - *Detroit Хлоя* (широкий кинематографичный портрет)
  - *Cyberpunk Pink* (неоновый ночной город)
  - *Cyberpink Fuji* (футуристическая гора Фудзи)
  - *Cyber Butterfly* (кибер-бабочка в неоновых лучах)
  - *Tokyo Night* (атмосферные улицы Токио)
  - *Celestial Palace* (космический неоновый дворец)
- **Загрузка пользовательских обоев:** возможность загрузить любое изображение (PNG, JPEG, WebP) — браузер моментально определит лидирующий цвет и обновит цветовую палитру интерфейса.
- **Натуральное отображение веб-сайтов:** веб-страницы сохраняют свои оригинальные нативные цвета без принудительной перекраски сторонними стилями.

### ⚡ 2. Умная панель вкладок (как в Google Chrome)
- **Оптимальный размер:** до 10 вкладок сохраняют комфортную стандартную ширину с полным отображением заголовков и фавиконов.
- **Динамическое сжатие:** при открытии более 10 вкладок заголовки начинают плавно и аккуратно сжиматься, предотвращая переполнение экрана (полный аналог поведения Google Chrome).
- **Продвинутое управление:** перетаскивание (drag & drop) для изменения порядка, закрепление, отключение звука на вкладке, дублирование, закрытие вкладок справа/других.
- **Автоматическое усыпление:** интеллектуальная выгрузка фоновых страниц из памяти при простое (с защитой активных форм, воспроизведения медиа и загрузок).

### 🔍 3. Умная адресная строка (Omnibox Suggestions)
- **Мгновенные подсказки при вводе:** удобное выпадающее меню с рекомендациями сайтов на лету.
- **Каталог популярных сервисов:** быстрое автодополнение для десятков сайтов (ВКонтакте, YouTube, Яндекс, Google, Pinterest, Telegram, Mail.ru, Дзен, Кинопоиск, Хабр, Ozon, Wildberries, Авито, Госуслуги, Rutube, Википедия, GitHub, Twitch, Reddit, Discord, Иви, Т-Банк, СберБанк, Steam, Пикабу, РИА Новости, РБК и др.).
- **Поиск по русским и английским названиям и алиасам:** ввод `вк`, `ют`, `ya`, `pin`, `тг`, `wb`, `сбер`, `фильмы`, `почта` сразу выдаёт нужный сайт с прямым переходом.
- **Умное объединение:** подсказки также анализируют ваши сохраненные **закладки** и **историю**, а последним пунктом предлагают прямой веб-поиск.
- **Клавиатурная навигация Google Chrome:** навигация стрелками <kbd>↑</kbd> / <kbd>↓</kbd> с динамическим предпросмотром URL прямо в строке адреса, восстановление введенного текста по <kbd>Esc</kbd> и быстрый переход по <kbd>Enter</kbd>.

### 📥 4. Загрузки в стиле Google Chrome с Drag-and-Drop и умным медиа-загрузчиком
- **Выпадающее меню загрузок (Chrome Downloads Bubble):**
  - Быстрый доступ к активным и недавним загрузкам по кнопке на панели инструментов.
  - **Нативный Drag-and-Drop:** перетаскивание любого скачанного файла прямо из списка загрузок в поле ввода/отправки любого сайта, мессенджера или редактора.
  - **Кнопка повторной загрузки:** быстрый перезапуск скачивания в один клик для любого завершённого или прерванного файла.
  - Открытие файла и быстрый переход в папку проводника.
- **Скачивание видео (MP4):**
  - Поддержка VKontakte (включая модальные видео из ленты `z=video...`, клипы и разделы видео), YouTube, Rutube, прямых потоков.
  - Высокое качество с автоматическим объединением видео и звука (на базе `yt-dlp`).
- **Скачивание музыки (MP3):**
  - **ВКонтакте:** удобные кнопки `⬇` в каждой строке трека плейлиста для мгновенного скачивания с сохранением правильного тега `Исполнитель - Название.mp3`.
  - **Кнопка в верхнем плеере VK:** кнопка `⬇ MP3` для сохранения играющей дорожки в один клик.
  - **Автоматический перехват аудиопотоков:** возможность конвертации любого играющего медиапотока в MP3.
- **Улучшенное скачивание с Pinterest:**
  - Извлечение фото в максимальном исходном разрешении `/originals/` и прямое сохранение MP4 видеороликов через анализ `__PWS_DATA__`.
  - Интеллектуальный контекстный выбор медиа по клику правой кнопкой мыши через `elementsFromPoint`.
  - Поддержка коротких ссылок `pin.it`.
- **Полнофункциональный менеджер загрузок:**
  - Отображение точного размера файла, прогресса и скорости.
  - Поддержка **паузы** и **возобновления** загрузок.
  - Отмена и удаление записей (с возможностью удаления файла с диска).

### 👤 5. Google Аккаунт, SSO и Всплывающие Окна Авторизации (Popup OAuth Windows)
- **Нативные всплывающие окна авторизации (Popup Windows):**
  - Поддержка всплывающих диалоговых окон для входа через внешние сервисы (Google, VKontakte, Яндекс ID, Telegram, GitHub, Apple ID, Facebook и др.).
  - Окна открываются как аккуратные отдельные всплывающие окна по центру родительского окна с сохранением точных пропорций (`width`/`height`), без лишних вкладок и панелей адреса.
  - Полноценная поддержка `WindowProxy`, двустороннего обмена сообщениями `window.opener.postMessage` и автоматического чистого закрытия по `window.close()`.
- **Единый центр аккаунтов Google:** специальная кнопка Google в шапке браузера с отображением аватара, имени и email активного профиля.
- **Мультиаккаунтность:** добавление нескольких аккаунтов Google и быстрое переключение между ними в один клик.
- **Бесшовный One-Tap и OAuth:** сайты (например, Pinterest, сервисы Google и партнерские платформы) автоматически распознают авторизованный аккаунт Google через Google Identity Services (GIS) и предлагают вход в один клик без блокировки cookies.
- **Синхронизация сессий:** все всплывающие окна авторизации делят общую сессию браузера, благодаря чему вход на сторонних сайтах подхватывает уже сохраненный аккаунт мгновенно.

### 🛡️ 6. Приватность, Безопасность и Встроенный VPN
- **Интерактивная Панель Приватности (Privacy Dashboard):**
  - Диагностика безопасности в реальном времени: статус внешнего IP (IPv4/IPv6), активный сетевой маршрут (Direct, Browsec, Proxy).
  - Мониторинг DNS-серверов и детальные тесты на утечки данных (WebRTC Leak Check, DNS Leak Check, изоляция сторонних cookies).
  - Счётчик заблокированных трекеров и рекламы с детализацией по топ-доменам.
  - Централизованное управление разрешениями сайтов (уведомления, cookies, исключения блокировщика).
- **Встроенный soulm8te VPN:**
  - Быстрое проксирование с выбором серверов (Нидерланды, Сингапур, США, Великобритания и др.).
  - **Умные правила (SmartSettings):** автоматическое переключение локаций или прямое подключение без VPN для заданных доменов.
  - **Адаптивный дизайн:** полная читаемость всех кнопок, переключателей и статусов в светлых и тёмных темах.
- **Интеллектуальный блокировщик рекламы:**
  - Встроенный движок фильтрации рекламы и трекеров (FilterEngine) по популярным правилам.
  - **Точечное отключение на конкретных сайтах:** переключатель в меню защиты в один клик для любого домена (YouTube, VK, Habr и др.).
  - **Белый список в настройках:** раздел «Сайты, где блокировщик выключен» с быстрым удалением сайтов из исключений и ручным добавлением доменов.
- **Приватный режим (Инкогнито):** запуск изолированной сессии в оперативной памяти (без записи истории, cookies и кеша на диск) с отдельным неоновым фиолетовым оформлением.

### 🧹 7. Click & Clean — Экспресс-очистка следов и приватности
- **Мгновенное удаление цифровых следов:**
  - Очистка кэша Chromium, HTTP-кэша, шейдеров GPU, Code Cache и DawnWebGPUCache.
  - Удаление cookies из защищенной SQLite-базы данных и очистка активных сессионных cookie.
  - Полное удаление истории посещений (с историей переходов внутри вкладок) и журнала загрузок.
  - Очистка веб-хранилищ сайтов: LocalStorage (LevelDB), SessionStorage, IndexedDB, Service Workers и CacheStorage.
  - Сброс кэша HTTP-аутентификации (Basic/Digest/NTLM) и DNS-кэша Host Resolver.
- **4 готовых смарт-пресета:**
  - 🚀 **«Быстрая очистка»:** кэш страниц, история переходов, недавно закрытые вкладки и DNS.
  - 💳 **«После онлайн-оплаты»:** куки, токены авторизации, веб-хранилища, кэш и сессии платежей.
  - 🛡️ **«Чужой компьютер / Kiosk»:** тотальное уничтожение всех следов и экстренное закрытие вкладок.
  - ⚙️ **«Пользовательская»:** ручной детальный выбор любого компонента с гибкой настройкой.
- **Живые HUD-метрики в реальном времени:**
  - Отображение точного объема занимаемого кэша (в МБ/ГБ), количества сохраненных cookies, записей истории, загрузок, открытых вкладок и паролей.
- **Защита паролей (Password Guard):**
  - Защитный барьер от случайного удаления паролей с предупреждающим диалогом и обязательным чекбоксом подтверждения.
- **Быстрый доступ:**
  - Горячая клавиша <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Del</kbd> (<kbd>Cmd+Shift+Del</kbd>).
  - Иконка клининга ✨ на верхней панели браузера и пункт в главном меню.

### Две страницы рядом и перенос закладок

- Кнопка «Две страницы рядом» на панели позволяет выбрать вторую обычную веб-вкладку того же рабочего пространства. Пропорции — 50/50, 35/65 и 65/35; в узком окне страницы располагаются одна над другой. Фокус меняет адресную строку, сохраняя физическое расположение панелей. Выход оставляет обе вкладки открытыми.
- В менеджере закладок доступны импорт и экспорт HTML. Экспорт создаёт совместимый Netscape bookmarks файл через системный выбор места сохранения; cookies и пароли в него не включаются.

### 🧵 8. Автономный AI-Ассистент Вуду (Browser Agent & STT Voice Commands)
- **Автономный агент браузера (Browser Agent Loop):**
  - Вуду способен самостоятельно управлять браузером, выполняя сложные многошаговые сценарии (без фиксированного ограничения количества раундов и действий, с обратной связью и остановкой повторов без прогресса).
  - **Контекст:** локальный бюджет до 250 000 токенов (по умолчанию); system/tools/history и резерв ответа учитываются вместе. Поддержка такого объема зависит от выбранной модели и endpoint; интерфейс показывает приблизительную оценку, а не обещает емкость провайдера. Большие контексты могут увеличивать latency.
  - **Производительность:** нет автоматических тестовых completion-запросов на старте; кешируется совместимость API, ограничены журналы и отрисовка истории, скрытые страницы приостанавливают необязательные DOM-сканирования.
  - Для составной задачи используется `update_plan`: этапы остаются в контексте, а преждевременный текстовый итог не закрывает незаконченный план. Повторы без новых результатов ограничены, кнопка «Стоп» прерывает запрос.
  - `read_page` возвращает ссылки и `next_start` для продолжения длинной страницы; `read_file` поддерживает такой же обход текстового файла. `create_file` сохраняет текст в Downloads/Desktop/Documents, перезапись требует явного параметра.
  - Совместимость с API без native tools: история переводится в обычные текстовые сообщения, включая результаты уже выполненных действий. Обрезанные провайдером команды не выполняются.
  - Подробности и ограничения: [YouTube и надежность браузера](docs/BROWSER_RELIABILITY_AUDIT_2026-10-28.md), [аудит приложения и новых функций](docs/APPLICATION_AUDIT_2026-10-28.md), [предыдущий аудит сложных запросов](docs/VOODOO_WORKFLOWS_AUDIT_2026-10-28.md).
  - **Основные инструменты браузера:**
    1. `search_web`: интеллектуальный поиск в интернете в текущей или новой вкладке.
    2. `open_url`: открытие любого веб-сайта по адресу.
    3. `list_tabs`: получение списка всех открытых вкладок с заголовками и URL.
    4. `switch_tab`: моментальное переключение на нужную вкладку.
    5. `close_tab`: закрытие текущей или любой указанной вкладки.
    6. `read_page`: извлечение текста, заголовков и сути открытой страницы.
    7. `get_page_elements`: обнаружение кнопок, ссылок и полей формы на сайте.
    8. `click_element`: клик по кнопке или ссылке по видимому тексту или селектору.
    9. `fill_input`: ввод текста в формы/поисковые строки сайтов с опциональной отправкой.
    10. `scroll_page`: прокрутка страницы вверх/вниз/в начало/в конец.
    11. `execute_script`: выполнение JavaScript в контексте страницы с ограничением ожидания; это не доступ к Node.js или оболочке ОС.
    12. `get_active_dialog`: извлечение переписки активного диалога ВКонтакте или Telegram.
    13. `clean_browser`: запуск экспресс-очистки данных Click & Clean.
  - **Визуальные бейджи действий:** отображение интерактивных статусов выполнения каждого действия агента в чате (`.voodoo-action-pill`).
- **🎙️ Голосовые команды с STT (Speech-to-Text):**
  - **Кнопка микрофона:** отдельная неоновая кнопка активации в поле ввода и в быстрых действиях.
  - **Распознавание речи в реальном времени:** живое отображение произносимых слов прямо в строке ввода с динамической анимацией звуковых волн.
  - **Автоматическая отправка:** после завершения фразы распознанный текст автоматически отправляется ассистенту Вуду так же, как обычная текстовая команда.
  - **Звуковые эффекты Cyberpunk:** футуристичные звуковые сигналы начала и завершения записи голоса на базе Web Audio API без внешних файлов.
  - **Разговорные команды:** понимание естественных запросов (*«Вуду, найди рецепт пиццы»*, *«Открой Ютуб»*, *«Прочитай что на этой странице»*, *«Закрой вкладку»*, *«Очисти историю»*).
- **Точный анализ диалогов ВКонтакте:**
  - Интеллектуальное распознавание текущего активного собеседника (через `cur.peer`, параметры URL `sel`/`convo` и фильтрацию только видимых DOM-контейнеров `!_im_peer_history_hidden`).
  - Разделение входящих и исходящих сообщений с генерацией 3-4 готовых вариантов ответа (*С юмором*, *Дружеский*, *Чёткий*, *Вежливый*).
  - Кнопки быстрого копирования и прямой вставки ответа в поле ввода сайта в 1 клик.
- **8-осевой ресайзинг окна чата:**
  - Изменение размеров окна Вуду за любой из 4 углов (с тактильным уголком-гриппером) или за любую из 4 сторон.
  - Сохранение удобного масштаба и позиции с защитой от выхода за пределы экрана.
- **Плавающий кружок-аватар при сворачивании:**
  - При сворачивании окна Вуду (кнопки «—», «✕», клавиша <kbd>Esc</kbd> или <kbd>Ctrl+Shift+V</kbd>) ассистент сворачивается в компактный кружок с аватаром, зелёным LED-статусом и неоновым пульсирующим кольцом в правом нижнем углу.
  - Кружок гарантированно отображается поверх абсолютно всех сайтов и открытых вкладок.
  - Поддерживает перетаскивание (drag-and-drop) в любую удобную часть экрана, а при одиночном клике мгновенно разворачивает окно диалога обратно.
- **Продвинутый пул ключей xkiro:**
  - Мониторинг здоровья ключей (`healthy`, `exhausted`, `invalid`) и авто-ротация при лимитах (429/402/403) с кулдауном 5 минут.
  - Массовая вставка ключей, смена приоритетов и кнопка мгновенного тестирования задержки ⚡ в Настройках.

### 🔍 9. Масштабирование страниц как в Google Chrome (Ctrl + Колесо мыши)
- **Нативное управление масштабом:**
  - Зажмите <kbd>Ctrl</kbd> (или <kbd>Cmd</kbd>) и крутите колесо мыши: **от себя** — приближение, **на себя** — отдаление.
- **17 дискретных масштабов Chromium:**
  - `25%`, `33%`, `50%`, `67%`, `75%`, `80%`, `90%`, `100%`, `110%`, `125%`, `150%`, `175%`, `200%`, `250%`, `300%`, `400%`, `500%`.
  - Устраняет артефакты дробного окружения и размытия шрифтов.
- **Индикатор в Omnibox:**
  - Автоматическое появление бейджа с текущим процентом масштаба в адресной строке при отличии от 100%.
  - Клик по бейджу мгновенно сбрасывает масштаб страницы обратно на `100%`.

### 🔐 10. Сохранение и управление паролями (Password Manager)
- **Автоматический перехват форм авторизации:**
  - Фоновый перехват отправки логинов и паролей на HTTPS-страницах без сторонних расширений.
- **Всплывающий диалог в стиле Cyberpunk:**
  - Плавное появление плавающего окна под строкой адреса: *«Сохранить пароль?»* или *«Обновить пароль?»*.
  - Отображение домена, редактируемый логин и пароль, кнопка показа/скрытия пароля (`Eye`/`EyeOff`), опция *«Никогда для этого сайта»*.
- **Полнофункциональный менеджер паролей:**
  - Встроенный генератор надежных паролей (✨).
  - Просмотр сохраненного пароля по клику на иконку глаза и быстрое копирование логина/пароля в буфер обмена (`Copy`).
  - Быстрое автозаполнение сохраненных реквизитов прямо из выпадающего меню адресной строки (Omnibox).
  - Защищенное шифрование данных на диске с помощью Chromium safeStorage.

### 📊 11. Диспетчер задач Chromium (Chrome Task Manager, Shift+Esc)
- **Вызов горячей клавишей:** вызов по <kbd>Shift</kbd> + <kbd>Esc</kbd> или через главное меню браузера.
- **Мониторинг в реальном времени:**
  - Живое обновление каждую секунду показателей всех процессов: Browser (ядро), Shell (интерфейс), GPU (графический стек), Tabs (каждая веб-вкладка), Utility (сеть и расширения).
  - Отображение точного **PID**, потребления памяти (**RAM в МБ/ГБ**) и нагрузки на процессор (**CPU %**).
  - Цветовая индикация нагрузки: зеленая (норма), оранжевая (>50%), неоново-красная (>80%).
- **Завершение зависших процессов:**
  - Принудительное завершение упавших или зависших вкладок кнопкой *«Завершить процесс»* с защитой критических системных процессов браузера.

### 🛠️ 12. Режим разработчика (DevTools) без артефактов
- Нажмите <kbd>F12</kbd> (или <kbd>Ctrl+Shift+I</kbd>, либо пункт контекстного меню *«Просмотреть код»*), чтобы открыть инструменты разработчика Google Chrome:
  - **Чистый рендеринг без артефактов:** DevTools открывается в отдельном автономном окне, исключая тиринг, отрицательную задержку кадров и конфликты слоёв с интерфейсом браузера.
  - **Нативная тёмная тема:** фоновый цвет DevTools сразу инициализируется в тёмных тонах без белых вспышек.
  - **Инспектор DOM и стилей (Elements)**
  - **JavaScript-консоль (Console)**
  - **Анализ сетевых запросов (Network)**
  - **Отладчик скриптов (Sources)**
  - **Хранилище (Application: LocalStorage, Cookies, IndexedDB)**

### 🤖 13. Адаптивная страница ошибок и всплывающие окна
- **Единый дизайн диалоговых окон:** всплывающие окна защиты, уведомлений и авторизации гармонично подстраиваются под текущую тему оформления.
- **Фирменная иллюстрация ошибки сети («Сайт недоступен»):** при сбоях сети, ошибках DNS (`ERR_NAME_NOT_RESOLVED`), отказах сервера (`ERR_CONNECTION_REFUSED`) или таймаутах отображается плавная адаптивная карточка с роботом.
- **Понятная диагностика:** отображение точного адреса, кода ошибки и расшифровки на русском языке.
- **Быстрые действия:** кнопки *«Повторить попытку»*, *«Назад»* и *«Новая вкладка»*.

### 🖥️ 14. Стабильность графического стека на Linux (Wayland & X11) и российские сертификаты
- **Устранение графических артефактов и тиринга:**
  - Оптимизированный z-order нативных слоёв `WebContentsView` без паразитных циклов пересоздания подповерхностей Wayland (`wl_subsurface`).
  - Устранение просвечивания окон рабочего стола благодаря плотной фоновой заливке темы вьюпорта (`var(--canvas, #171b20)`).
  - Защита от паразитного выделения пустых буферов композитором (0x0 Bounds Guard).
- **Гарантированное отображение модальных окон над веб-страницами:**
  - Полный приоритет оверлеев: Click & Clean, всплывающие окна сохранения паролей, поиск по странице (<kbd>Ctrl</kbd> + <kbd>F</kbd>) и менеджер пространств всегда поднимаются поверх активного нативного веб-содержимого.
- **Встроенная поддержка сертификатов Национального удостоверяющего центра:**
  - Доверенная валидация цепочки сертификатов Минцифры РФ (Госуслуги, VK, Сбер, Mail.ru) без ложных предупреждений безопасности и сбоев SSL.
- **Оптимизация параметров Ozone / Wayland:**
  - Отключение конфликтующих модулей Vulkan на Wayland для максимальной стабильности аппаратного ускорения через OpenGL ES.

## Плавающий мини-плеер (PiP)

Включите PiP у загруженного видео и переключитесь на другую вкладку: видео остаётся в плавающем плеере внутри окна браузера. Перетащите заголовок, чтобы переместить его, или потяните нижний правый угол, чтобы изменить размер. Положение и размер сохраняются при переключении вкладок в текущем запуске; при уменьшении окна плеер остаётся в его границах.

Доступны пауза/воспроизведение, звук, перемотка на ±10 секунд, возврат к вкладке и закрытие мини-плеера. Перемотка выключена для потоков без конечной длительности. Активен один плеер; включение другого не ставит старое видео на паузу. Вкладка с PiP не выгружается системой сна.

## 🚀 Установка и запуск

### Требования
- **Node.js**: версия 24+
- **npm**: версия 10+
- **Linux / Windows / macOS**

В Linux штатный запуск требует работающего Chromium sandbox: разрешённых user namespaces либо корректно установленного SUID helper. Установщик `.deb` настраивает helper. Автоматического отключения sandbox при ошибке больше нет.

### Быстрый старт из исходного кода

```bash
# 1. Клонирование репозитория
git clone https://github.com/giddammit-crypto/MonkeyBuissnesBrowser.git
cd MonkeyBuissnesBrowser

# 2. Установка зависимостей
npm ci

# 3. Проверка тестов и типов
npm run check

# 4. Сборка приложения
npm run build

# 5. Запуск браузера
npm start
```

### Сборка релизных пакетов для Linux

```bash
# Сборка пакетов AppImage и .deb
npm run dist:linux
```
Готовые пакеты будут сформированы в каталоге `release/`.
